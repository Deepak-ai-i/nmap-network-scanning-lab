# Network Reconnaissance and Initial Security Assessment Using Nmap

## Project Overview
This beginner-level cybersecurity project demonstrates network reconnaissance and initial security assessment in an isolated virtual lab.

## Lab Environment
- Attacker Machine: Kali Linux
- Target Machine: Metasploitable 2
- Virtualization: Oracle VirtualBox
- Network: Internal Network (cyberLab)

## Tools Used
- Nmap
- Kali Linux
- Metasploitable 2
- VirtualBox

## Activities Performed
- Configured an isolated virtual network.
- Identified the target machine.
- Performed TCP SYN port scanning using Nmap.
- Identified open TCP ports and associated services.
- Captured screenshots of practical results.

## Target Information
- Kali Linux IP: 192.168.56.10
- Metasploitable 2 IP: 192.168.56.20

## Evidence
Practical screenshots are available in the `screenshots` folder.

## Project Status
Basic network reconnaissance and port scanning completed. Further enumeration learning and practical exercises are ongoing.

## Disclaimer
This project was performed in an isolated lab using an intentionally vulnerable virtual machine. No unauthorized systems were tested.
